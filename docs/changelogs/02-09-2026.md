# Changelog - 02 September 2026

## Unified GIS prospect workspace

- Expanded `/gis-enquiry` into a unified prospect list containing direct GIS enquiries and Fair Funnel leads whose event fair-code prefix equals `GIS` without case sensitivity.
- Preserved the original database models and event/consent records; the merged workspace is implemented at the query layer and does not duplicate or migrate lead data.
- Added a Source column and source filter to distinguish `GIS Enquiry` from `Fair Funnel` records.
- Extended search to Fair Funnel company names and fair codes.
- Added source-aware reply, assignment, lifecycle status, spam review, soft-delete, restore, details, and mixed-model bulk actions.
- Protected mixed bulk actions with record-type validation, the existing policies, visibility scopes, transactions, and a server-side GIS-prefix restriction.

## GIS Fair analytics

- Added a GIS Fair Dashboard covering every Fair Funnel event, including closed historical events.
- Added shared filters for event, submission date range, acquisition source, lifecycle status, marketing consent, business type, and country.
- Added registration and unique-prospect KPIs, qualification/customer conversion rates, repeat submissions, and current marketing-consent rate.
- Added daily registration trend, lifecycle pipeline, source and country breakdowns, and event performance comparisons.
- Kept confirmed/suspected spam and soft-deleted leads out of management analytics.
- Aggregated normalized acquisition sources through a subquery so the dashboard remains compatible with MySQL and MariaDB installations using `ONLY_FULL_GROUP_BY`.

## Navigation

- Converted GIS Fair Funnel into a non-clickable sidebar group.
- Added Dashboard, List All Prospect, and List All Event submenu destinations with permission-aware visibility.
- Added contextual Dashboard links to the existing Fair prospect and event pages.

## Quality assurance

- Added feature coverage for case-insensitive prefix matching, source filtering, mixed-model bulk actions, prefix-boundary enforcement, and dashboard filter consistency.
- Verified the dashboard views compile and the GIS prospect regression suite passes.
- No database migration is required for this release.
