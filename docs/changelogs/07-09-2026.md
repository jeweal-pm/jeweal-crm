# Changelog - 07 September 2026

## Fair Code fallback

- Fair Codes continue to use a Tracking URL's configured `fair_code_prefix` when a valid `trackingToken` is submitted.
- Fair Codes now fall back to the Event code when no Tracking URL prefix is available.
- For example, Event code `JWBGJF` now produces `JWBGJF-XXXXXX` instead of using the legacy Event `code_prefix` value.
- Updated the Tracking URL form help text to show the actual Event code used by the fallback.

## Quality assurance

- Updated the Fair Funnel regression coverage for Event-code Fair Code fallback.
