# Changelog - 1 September 2026

## Enquiry Bulk Actions

- Added row selection checkboxes and select-all controls to Jeweal Enquiries, GIS Enquiries, GMS Enquiries, and GIS Fair Leads.
- Added a reusable bulk action bar with Delete, Restore, Assign, and Change status actions based on the current user's permissions.
- Added atomic server-side bulk processing for up to 100 selected records.
- Added record visibility checks, per-record policy authorization, active sales-assignee validation, and bulk-delete permission enforcement.
- Preserved workflow activity logging for modules with and without the `deleted_by` audit column.
- Added selected-row highlighting, live selected counts, contextual controls, and responsive mobile layout.

## Confirmation Dialogs

- Replaced native browser confirmation prompts with a reusable dialog centered in the viewport.
- Added keyboard Escape handling, backdrop dismissal, focus restoration, accessible dialog labels, and action-specific button styling.
- Applied the shared dialog to enquiry deletion, GIS Fair management, WhatsApp record deletion, IP blacklist removal, email enrollment removal, and sequence-step removal.

## Compatibility

- Rechecked the implementation against commit `0a9ee72`, which made GIS Fair company data optional.
- GIS Fair lead lists now display `Not provided` when company information is empty.

## Verification

- Added feature coverage for all four enquiry workspaces and bulk-action endpoints.
- Verified atomic rollback when a selected record is unavailable.
- Verified users without `enquiry.bulk_delete` cannot submit bulk deletions directly.
- Blade view compilation and Laravel Pint checks passed.
