# Changelog - 04 September 2026

## Tracking URL Fair Code prefixes

- Added an optional `fair_code_prefix` field to every GIS Fair Tracking URL.
- Generated Fair Codes now use the Tracking URL prefix when configured, for example `PARTNER-ABC123`.
- Tracking URLs without a custom prefix continue to use the Event `code_prefix` as the default.
- Preserved the generated Fair Code on the lead so API responses, customer emails, internal emails, CRM detail pages, and later resends use the same value.
- Added uppercase normalization and validation for Tracking URL prefixes.

## Administration

- Added Fair code prefix fields to both the create and edit Tracking URL forms.
- Added the nullable `gis_fair_tracking_links.fair_code_prefix` database column.

## Quality assurance

- Added coverage for custom Tracking URL prefixes and Event-prefix fallback behavior.
- Added coverage confirming the selected Fair Code is rendered in the customer email.
- Added coverage confirming a lead's business country can differ from the phone country.
- Verified the complete Laravel test suite passes all 82 tests.
