- Added `CommunicationSecuritySeeder` and `GisFairFunnelSeeder`.
- Updated `.env.example`, CORS configuration, queue defaults, and local Docker services.

Run after deployment:

```bash
php artisan migrate --force
php artisan db:seed --class=RolePermissionSeeder --force
php artisan db:seed --class=CommunicationSecuritySeeder --force
php artisan db:seed --class=GisFairFunnelSeeder --force
php artisan optimize:clear
```

The seeded GIS Fair campaign starts in `Draft`. Review its event details and change it to `Active` before accepting public registrations.

The server scheduler must execute `php artisan schedule:run` every minute. A queue worker is also required when `QUEUE_CONNECTION=database`.
